RWX Baker
An Arknights: Endfield message generator. A pixel-faithful, in-browser recreation of the in-game Baker messaging app. Build 1-on-1 or group conversations with all operators, NPCs, stickers and emojis, add choices and reactions, then export as high-res PNG. 100% client-side, no ads, no trackers.
 live – rwyn.app/RWX-Chimera
RWX Chimera
A high-entropy password generator and encoder/decoder forge. Type a catchphrase you can actually remember, split it in two, encode each half (hex, base64, base32, base58, binary, rot13), then add an extra word and a suffix to get a 40–60 character password. Comes with a quick decoder and an offline zxcvbn strength tester with crack-time estimates. Windows XP Luna look, 9 languages, 100% client-side. The web version is for when you can't install anything; the standalone .exe lives on GitHub Releases.
