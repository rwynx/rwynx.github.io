The short version

This is a personal, non-commercial site. I don't run ads, I don't sell anything, and I don't track you. The tools on this site (NovelAI Metadata Inspector, Background Remover, Image Resizer) process everything — images, PNGs, whatever you feed them — entirely inside your own browser. Nothing you upload into a tool on this site is ever sent to me, to a server, or to any third party.

What I don't do

  • No accounts, no sign-ups, no logins.
  • No analytics, no ad trackers, no cookies set by me.
  • No file uploads for any of the tools — they run client-side, in your browser, using JavaScript and the Canvas/WebAssembly APIs. I never see what you put into them.

What does happen, outside my control

This site is static and hosted on GitHub Pages, and uses a couple of standard third-party services that any visitor's browser talks to directly:

  • GitHub Pages hosting — like any web host, it keeps standard server logs (things like your IP address and browser type) for the pages you request. I don't have special access to this beyond what GitHub provides.
  • Google Fonts — this site loads a couple of fonts from Google's font CDN (fonts.googleapis.com / fonts.gstatic.com), which means your browser makes a direct request to Google to fetch them, and Google can see the request (including your IP) the same way it would for any font request on any site.
  • The Background Remover tool loads an AI model from a public CDN (jsDelivr) the first time you use it — again, your browser fetches it directly, no data about your image is involved, it's just downloading the model files themselves.
